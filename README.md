# DataLens AI
### Intelligent No-Code Data Analysis Platform

**Final Year Major Project**

## Features
- **Upload:** Support for CSV/Excel (Tabular data only).
- **AI Chat:** Natural language processing via Google Gemini.
- **Auto-Cleaning:** Automated data sanitization.
- **Visualization:** Dynamic Plotly charts.
- **Reporting:** Downloadable HTML reports.

## Architecture
- **Frontend:** Streamlit
- **Backend Core:** Python (Pandas/NumPy)
- **AI:** Gemini (JSON Mode)

## Setup
1. Create venv: `python -m venv venv`
2. Activate venv.
3. Install: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
